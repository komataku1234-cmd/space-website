## Overview

### The challenge

ユーザーができること:

- デバイスの画面サイズに応じて、各ページの最適なレイアウトを表示する
- ページ上のすべてのインタラクティブ要素のホバー状態を確認する
- 各ページを閲覧し、タブを切り替えて新しい情報を確認する

### Screenshot

![](./screenshot.jpg)

ソリューションのスクリーンショットを追加してください。最も簡単な方法は、Firefox でプロジェクトを表示し、ページを右クリックして「スクリーンショットを撮る」を選択することです。ページの長さに応じて、全体のスクリーンショットまたは切り取ったものを選べます。ページが非常に長い場合は、切り取る方が良いでしょう。

または、[FireShot](https://getfireshot.com/) のようなツールを使うこともできます。FireShot には無料オプションがあるので、購入する必要はありません。

その後、画像をお好みに合わせてトリミング・最適化・編集し、プロジェクトに追加して、上記の画像のファイルパスを更新してください。
