# Figma デザインファイルの使い方

このデザインファイルを使うことで、プロが行っているのと同じ方法でプロジェクトを構築する練習ができます。デザインの細部を見ることで、精度が上がり、より速くプロジェクトを構築できるようになります。

[Figma](https://www.figma.com/) は非常に人気のあるデザインツールで、無料プランも充実しており、Windows と Mac の両方に対応しています。

Figma を使い始めるには、[お使いの OS に合ったアプリをダウンロードしてください](https://www.figma.com/downloads/)。アプリを開いたら、`.fig` デザインファイルをアプリにドラッグするか、「import」ボタンを使って開くことができます。

デスクトップアプリを使う場合は、ダウンロードページからフォントインストーラーをダウンロードする必要はありません。ただし、Figma のウェブアプリを使う予定がある場合は、フォントが正しく表示されるようにダウンロードしてインストールしておくことをお勧めします。

Figma を使ったことがない場合は、私たちの記事「[Figma for developers: How to work with a design file](https://www.frontendmentor.io/articles/figma-for-developers-how-to-work-with-a-design-file-m6CZKZ1rC1)」を読むことをお勧めします。

---

**⚠️ 重要 ⚠️: デザインファイルを他の人と共有しないようご注意ください。誤って GitHub にアップロードしてしまうことを防ぐため、スターターコードのダウンロードには `.gitignore` ファイルを含めています。デザインファイルをコードベースとは別の場所に保管しておくのも、簡単な予防策です。**
